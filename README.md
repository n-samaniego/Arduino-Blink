# Bare-Metal Code for an Arduino UNO, A Simple Blink Journey

This is the start of my foray into Embedded Programming; a simple Blink program! While nothing too impressive in terms of complexity, this project is simply a way to get my feet wet in the world of C, Embedded Programming, Systems Programming, and using Git/Github for version control.

> [!note]
> First, an AI disclaimer. I consulted with Claude AI on a regular basis for help on this project, but I wrote and understand every line of code in my programs. I use Claude as a mentor, not as something to generate code for me. It would defeat the purpose of this project, and actively hurt my learning process. 

This project has 4 Parts. Part 1 is writing the program in C with the use of **avr-libc**. Part 2 is still in C, but without the use of **avr-libc**. Part 3, I move into using AVR assembly. Part 4, I implement the program in C with in-line assembly. 

There's a reason I am doing these parts and in the exact order I'm doing them in. With each successive part, I want to learn more about bare-metal progrgamming, understand the C language on a deeper level, and tear away some of the abstractions that some people take for granted. 

***journal.md*** is a semi-structured log of insights and experiences throughout each part of my project, from before Part 1 with set-up and reading some data sheets, to the very end with my final program. While mostly for me to come back to and see what I've learned, it's also documentation. I want to show that I've done the work, and I think having my journal here will help whoever else comes across my project to understand me better and maybe give them some insights as well!
